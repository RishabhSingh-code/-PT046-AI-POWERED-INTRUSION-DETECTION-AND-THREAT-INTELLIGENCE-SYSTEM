# -PT046-AI-POWERED-INTRUSION-DETECTION-AND-THREAT-INTELLIGENCE-SYSTEM
AEGIS is an AI-powered Intrusion Detection and Threat Intelligence System designed to monitor security alerts, visualize network traffic, identify potential cyberattacks, and demonstrate automated threat response.

## Features

* Interactive security monitoring dashboard
* Simulated security alerts and attack severity classification
* Network traffic visualization using Chart.js
* Threat intelligence and IP reputation panels
* MITRE ATT&CK technique mapping
* Simulated automated and manual response workflows
* Alert details and response logs

## Technology Stack

* HTML5
* CSS3
* JavaScript
* Chart.js

## Current Status

This project is currently a frontend prototype that uses synthetic data to demonstrate security monitoring workflows. Real-time network traffic monitoring, machine-learning integration, external threat intelligence APIs, and actual threat mitigation are planned for future development.

## Disclaimer

This prototype is intended for educational and demonstration purposes. It does not perform actual network intrusion detection or block real cyberattacks.
